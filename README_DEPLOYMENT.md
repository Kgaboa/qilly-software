## 🆘 **NEED HELP?**

### **Quick Issues:**

**Build fails?**
```bash
rm -rf node_modules package-lock.json
npm install
npm run build
```

**Page shows blank after deployment?**
- Check browser console (F12)
- Verify `vercel.json` file exists (it does! ✅)

**Document downloads don't work?**
- Test locally first: `npm run preview`
- Check if all libraries installed: `npm install`
