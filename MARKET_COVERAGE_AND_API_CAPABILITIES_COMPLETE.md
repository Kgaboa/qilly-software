## ✅ How to Use the New API Capabilities

### Step 1: Open Admin Dashboard
Navigate to **Admin Dashboard → Supplier API** tab

### Step 2: Click "API Management" Tab
You'll see all 96 suppliers listed

### Step 3: Select a Supplier
Click "Manage API" button next to any supplier

### Step 4: Configure API Integration

**For Manual Upload:**
1. Click "Manual Upload" tab
2. Fill in product details (code, description, unit, price)
3. Click "Add Product"
4. Repeat for all products
5. Click "Upload X Products to Database"

**For Web Scraping:**
1. Click "Web Scraping" tab
2. Enter target URL (supplier website)
3. Configure CSS selectors for data extraction
4. Set scraping schedule (daily recommended)
5. Click "Test Scraper" to verify
6. Click "Save Scraping Configuration"

**For REST API:**
1. Click "REST API" tab
2. Enter API base URL
3. Select authentication type
4. Enter API key/token
5. Configure endpoints (products, pricing)
6. Set sync frequency
7. Click "Test Connection"
8. Click "Save API Configuration"

**For CSV Import:**
1. Click "CSV Import" tab
2. Download CSV template (optional)
3. Upload your CSV file
4. Map columns to fields
5. Click "Import [filename]"

### Step 5: Monitor Status
- Green checkmark = Success
- Red X = Error (check configuration)
- Test before saving configuration
