## ✅ 3. ETENDER API INFRASTRUCTURE

### New File Created: `/src/utils/eTenderAPI.ts`

### Complete API Infrastructure:

#### A. Data Structures

**`ETenderSubmissionPayload`** - Comprehensive tender submission format:
- Core tender information (ID, reference, dates)
- Contractor information (company, CIDB, BBBEE, contacts)
- Financial information (BOQ total, compliance, P&G, green premium)
- Bill of Quantities (full item list with pricing)
- Compliance & Certifications (NHBRC, CIDB, BBBEE, tax, insurance)
- **Green Building & Environmental:**
  - Carbon metrics (emissions, savings, ROI)
  - NEMA compliance (score, risk, cost, timeline)
  - Waste management (volume, recycling rate, disposal cost)
  - EMP inclusion flag
- Collusion risk assessment
- Project timeline with milestones
- Supporting documents (BOQ, certificates, SBD forms)
- Metadata (generated by Qilly, version, checksum)

**`ETenderSubmissionResponse`** - API response format:
- Success/failure status
- Submission ID & receipt number
- Status (Received, Under Review, Accepted, Rejected, Queried)
- Timestamp
- Next steps guidance
- Validation errors (if any)

**`ETenderStatusResponse`** - Status check format:
- Current status and stage
- Progress percentage
- Timeline (received, under review, evaluated, awarded)
- Evaluator comments
- Outstanding queries
- Award status (if applicable)

#### B. API Functions

**`submitToETender()`**
- **Production Mode:** Connects to real eTender API
  - URL: `https://api.etender.gov.za/v1/submissions` (configurable via env variable)
  - Bearer token authentication
  - Full error handling
- **Simulation Mode:** Returns mock response for development/demo
  - Validates required fields (CIDB, BBBEE, tax clearance)
  - Generates realistic receipt numbers (e.g., `ET-JHB-2026-1234`)
  - 2-second network delay simulation
  - Returns next steps guidance

**`checkETenderStatus()`**
- **Production Mode:** Queries real eTender API for submission status
- **Simulation Mode:** Returns mock status with progress tracking

**`buildETenderPayload()`**
- Helper function to convert Qilly BOQ data to eTender format
- Maps all Qilly data structures to API payload
- Includes green metrics, environmental compliance, collusion risk
- Generates milestones and timeline automatically

#### C. Environment Variables Required (Production):
```
NEXT_PUBLIC_ETENDER_API_URL=https://api.etender.gov.za/v1/submissions
NEXT_PUBLIC_ETENDER_API_KEY=<secret_key_from_etender>
```

#### D. Usage Example:

```typescript
import { buildETenderPayload, submitToETender } from '@/utils/eTenderAPI';

// Build payload from Qilly data
const payload = buildETenderPayload(
  boqData,
  contractorData,
  complianceData,
  carbonData,
  environmentalData,
  {
    tenderId: 'T-2026-0123',
    tenderReference: 'JHB/2026/HOUSING/001',
    projectName: 'Affordable Housing Project',
    closingDate: '2026-04-15T17:00:00Z',
  }
);

// Submit to eTender (simulation mode for now)
const response = await submitToETender(payload, 'simulation');

if (response.success) {
  console.log('Receipt Number:', response.receiptNumber);
  console.log('Next Steps:', response.nextSteps);
} else {
  console.error('Errors:', response.errors);
}
```
