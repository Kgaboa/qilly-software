## 📞 SUPPORT & TROUBLESHOOTING

### **Not Seeing Compliance Calculator?**
1. ✅ Process a BOQ first (click "Process Bill of Quantities")
2. ✅ Scroll to bottom of results page
3. ✅ Check if "Show Compliance Costs" button is visible (might be hidden)

### **CIDB Not Showing Warnings?**
1. ✅ Set contractor to GB2 (max R650K)
2. ✅ Create BOQ worth R5M+
3. ✅ Should show red warning about insufficient grade

### **Costs Seem Wrong?**
**Validate:**
- NHBRC: ~R4,850 per RDP unit (enrollment + inspections + insurance)
- Statutory: 13.75% of labour cost (labour typically 35% of project)
- Testing: 0.5-1% of project value
- Preliminaries: 15-25% of project value

### **Browser Errors?**
1. ✅ Open DevTools (F12) → Check Console tab
2. ✅ Clear cache → Hard refresh (Ctrl+Shift+R)
3. ✅ Try in Incognito/Private mode
