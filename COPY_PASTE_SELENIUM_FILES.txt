SETUP & RUN INSTRUCTIONS (After copying files)
================================================================================

Step 1: Install Dependencies
-----------------------------
cd selenium_tests
pip install -r requirements.txt

Step 2: Set Qilly App URL
--------------------------
# If running locally:
export QILLY_BASE_URL=http://localhost:5173

# If deployed to Vercel:
export QILLY_BASE_URL=https://your-app.vercel.app

Step 3: Run Tests
-----------------
# Full test suite:
python qilly_regression_suite.py

# With pytest (prettier output):
pytest qilly_regression_suite.py -v

# Generate HTML report:
pytest qilly_regression_suite.py --html=report.html --self-contained-html

Step 4: View Results
--------------------
# Terminal output shows pass/fail
# Screenshots saved to: selenium_tests/screenshots/
# HTML report: Open report.html in browser

================================================================================
TROUBLESHOOTING
================================================================================

Error: "ChromeDriver not found"
→ Solution: pip install webdriver-manager (should be in requirements.txt)

Error: "Connection refused"
→ Solution: Make sure Qilly app is running (npm run dev or deployed)

Error: "Element not found"
→ Solution: Increase wait time in line 27: WebDriverWait(cls.driver, 20)

Tests failing randomly?
→ Solution: Disable headless mode (comment out options.add_argument('--headless'))
