## What is CCS Candy?

### Product Overview

**Full Name:** CCS Candy (Construction Cost Software)  
**Company:** Candy Software Limited (UK, established 1985)  
**SA Presence:** Local distributor/reseller (Candy SA)  
**Product Type:** Desktop estimating software for quantity surveyors  
**Market Position:** Traditional QS tool (40+ years in market)

---

### What CCS Candy Actually Does

**Primary Function: Digital Takeoff & Estimating**

```
CCS Candy Workflow (QS using the software):

Step 1: Import CAD/PDF Drawings
├─ Upload architectural drawings (PDF, DWG, DXF)
├─ Software displays drawings on screen
└─ QS uses mouse to "measure" on screen (digital takeoff)

Step 2: Manual Measurement & Quantification
├─ QS clicks on drawing to measure lengths, areas, volumes
├─ Software calculates quantities automatically (e.g., wall area = length × height)
├─ Quantities linked to BOQ items
└─ Example: "Measure this wall → 45m² of brickwork"

Step 3: Apply Rates (Manual Selection)
├─ CCS Candy provides a RATE LIBRARY (database of unit rates)
├─ QS searches library: "brickwork 220mm" → finds rate: R680/m²
├─ QS manually selects this rate
├─ Software applies: 45m² × R680/m² = R30,600
└─ QS repeats for every BOQ item (one by one)

Step 4: Build-Up Rates (If needed)
├─ If rate not in library, QS builds custom rate:
│   ├─ Material: R340/m²
│   ├─ Labor: R280/m²
│   ├─ Equipment: R35/m²
│   └─ Total: R655/m²
└─ QS stores custom rate for future use

Step 5: Generate BOQ Report
├─ Software formats BOQ (table with items, quantities, rates, totals)
├─ Export to Excel/PDF
└─ Submit to client

Total Time: 3-7 days (depending on project size)
```

**Key Point:** CCS Candy is a **TOOL** for quantity surveyors. It helps them work faster, but **THE QS STILL DOES ALL THE WORK.**
