## 🎯 FREE Tier Philosophy

The FREE tier is designed as a **Training & Evaluation Platform** - NOT for production use. This strategic approach:

1. **Educates contractors** on Qilly's capabilities using real BuildAid 2025/2026 templates
2. **Demonstrates value** by showing BOQ structure and workflow (with encrypted pricing)
3. **Forces upgrades** for actual production work - driving conversions to paid tiers
4. **Reduces support load** by requiring contractor approval before accessing any tier

## 🎯 STRATEGIC BENEFITS FOR INVESTOR PITCH

### 1. **Clear Upgrade Path**
- FREE tier shows value without giving away the core product (pricing data)
- Natural friction points drive conversions to paid tiers
- Contractors can't use FREE tier for real work (must upgrade)

### 2. **Quality Control**
- Contractor approval required even for FREE tier
- Prevents spam/fake accounts
- Builds serious contractor database from day one

### 3. **Market Education**
- Contractors learn Qilly with real BuildAid templates
- Reduces onboarding time for paid tiers
- Creates familiarity before financial commitment

### 4. **Competitive Advantage**
- Encrypted pricing prevents competitors from scraping data
- Training mode showcases workflow without exposing IP
- Professional tier (R2,999) positioned as "real work starts here"

### 5. **Department of Human Settlements (DHS) Appeal**
- Green building features reserved for ENTERPRISE tier (R8,999)
- Government contracts typically require ENTERPRISE features
- Carbon tracking = differentiation for tender submissions

## 🔒 SECURITY NOTES

All FREE tier pricing data is encrypted at the component level:
- **Format:** `R ●●●●●●` for amounts, `●●●%` for percentages
- **Implementation:** `formatAmount()` function checks `contractorTier === 'free'`
- **Coverage:** BOQ items, compliance costs, P&G costs, totals, subtotals
- **No workarounds:** Cannot export to Excel, PDF has watermark
