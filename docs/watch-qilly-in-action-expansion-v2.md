# Watch Qilly in Action — Expansion Demo v2 (production-safe storyboard)

**Status:** Script and shot list prepared; video asset not yet replaced. Record only features demonstrated in the current approved environment. Do not show private contractor or supplier data.

## Target duration: 100–120 seconds

| Time | Visual / screen | Voiceover / caption |
|---|---|---|
| 0–10s | Qilly landing page, product identity | “Qilly connects tender pricing with construction planning and commercial decisions.” |
| 10–25s | Import Tender/BOQ, supported file types, reconciliation workspace | “Bring in an unpriced BOQ or tender document, review extracted line items, and reconcile the results before pricing.” **Label PDF/DOCX extraction as subject to configured service and manual review.** |
| 25–40s | BOQ pricing and matching statuses | “Use Qilly-owned pricing evidence and review items that need contractor input or approval.” Do not imply automatic approval. |
| 40–58s | Historical priced BOQ → Generate work packages | “Convert eligible priced BOQ items into draft work packages. Review exclusions, sequencing and dependencies.” |
| 58–75s | Programme of Works, monthly allocations, S-Curve | “Explore a draft construction programme and projected monthly cash flow.” Mark as planning scenario, not contractual baseline. |
| 75–90s | Allowables & Margin input, profit, margin and markup | “Enter estimated allowable costs to compare projected profit and margin across the programme.” **Do not claim this is live on customer UAT until release is verified.** |
| 90–103s | Tender CRM pipeline and supplier leads | “Track tender opportunities and manage supplier engagement in the same workflow.” Only demonstrate tested access and response flows. |
| 103–115s | Closing brand card, Import Tender/BOQ, Sign In | “From BOQ to programme and commercial insight — explore Qilly in action.” |

## Production requirements
- Preserve existing public landing-page layout, primary Import Tender/BOQ action, and Sign In handoff.
- Do not expose user emails, BOQs, supplier quotations, rates or margins in recordings. Use approved synthetic demo data.
- For any feature not yet promoted to controlled UAT, use a clearly labelled **Coming soon / development preview** scene, or omit it.
- Keep video muted by default, captions available, with replay/pause controls; avoid autoplay with sound.
- Verify mobile layout, links and playback before public deployment.
- Do not publish this script as if it were a completed video.

## Release acceptance
1. Video depicts only currently available or clearly labelled preview functionality.
2. All depicted totals reconcile: BOQ eligible value → programme → cashflow; margin = (selling value - allowable cost) / selling value.
3. No customer data or privileged interface shown.
4. Existing public navigation and sign-in behaviour unchanged.
5. Video asset updated only after reviewed recording and playback test.
